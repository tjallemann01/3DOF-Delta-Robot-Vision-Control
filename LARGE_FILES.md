# Large Original Project Files / Archivos originales de gran tamaño

## English

The supplied source package contains useful project artifacts that are intentionally not included in this browser-upload-ready package because of their size:

- `Coding/trabajo_final_servidor9-20-52-AM.vpp` — Cognex VisionPro project (~65.7 MB)
- `Design/delta 3.zip` — archived CAD/design package (~73.7 MB)
- `Design/Delta_TicTacToe.mp4` — demonstration video (~31.7 MB)

Recommended publication options:

1. Add them with **Git LFS**.
2. Attach them to a **GitHub Release**.
3. Host the demonstration video externally and link it from the README.

The main repository remains useful without these large binaries because it includes the Python control code, TIA Portal archive, engineering PDFs, design images, simulations, and VisionPro-related evidence.
